# FinGuard API

## Run locally

From the repository root:

```bash
pip install -r api/requirements.txt
```

Make sure the model artifacts generated by `notebooks/03_modeling.ipynb` are present in:

```text
models/
├── final_rf_model.pkl
├── scaler.pkl
├── isolation_forest.pkl
├── iso_score_scaler.pkl
└── pca_col_idx.pkl
```

Start the API:

```bash
uvicorn api.main:app --reload
```

Open the interactive API documentation at:

```text
http://127.0.0.1:8000/docs
```

### Health check

`GET /health`
